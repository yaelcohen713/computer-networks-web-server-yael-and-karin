COMPUTER NETWORKS PROJECT

Multi-Threaded HTTP/1.0 Server

This page is served directly from a Python TCP socket without Flask, Django, or another web framework.

How it works Read server facts

Low-level sockets

The server creates, binds, listens, accepts, receives, and sends using Python's socket API.

Concurrent clients

Every accepted connection is handled by a separate worker thread.

Safe file serving

Only approved folders can be accessed, and directory traversal attempts are blocked.
